# API 稳定性

## 公共契约

`0.1` 系列对以下接口提供兼容承诺：

- README 中记录的 `agent-webview` 命令行参数。
- 运行信息 JSON 的 `pid`、`base_url`、`token` 和 `docs_url` 字段。
- 控制器 `/v1` 下的 HTTP 路径、请求模型、响应模型和错误状态码。
- `/openapi.json` 中对应的接口定义。

worker 随机端口上的内部 HTTP API、`agent_webview` 包内模块和未记录的对象均为
实现细节。依赖方不应直接导入或调用这些接口。

## 版本规则

- `0.1.x` 补丁版本保持已有公共接口向后兼容，可以增加可选字段和新接口。
- 必须删除字段、改变字段含义或修改既有行为时，提升次版本并在变更日志中说明。
- 安全修复可以收紧危险行为，但应保留明确的迁移说明。
- 达到 `1.0.0` 后遵循语义化版本，并为废弃接口至少保留一个次版本的过渡期。

OpenAPI 结构和关键请求/响应由自动化测试保护。依赖项目在 `0.x` 阶段建议使用
`agent-webview~=0.1.0`，避免自动跨越次版本。
